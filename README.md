# Nexus Desktop

Manage your Discord server's teams and events from your desktop. Nexus Desktop is a Windows app that works together with the **Nexus** Discord bot, so you don't have to type slash commands for everything.

## Download

Get the latest installer from the **[Releases page](../../releases/latest)** and download `Nexus-Setup-x64.exe`.

> Always use the **Setup** installer if you want automatic updates. The Portable version does not update itself.

## Install

1. Download the Setup file from the latest release.
2. Run it. If Windows shows *"Windows protected your PC"*, click **More info → Run anyway**.
3. Sign in with Discord, pick your server and you're ready.

## Features

- Create and manage teams, and rename them or change their class/focus at any time
- Plan events, post results and run attendance
- Handle sign-ups, penalty points and steward decisions
- Send announcements and delete app posts you no longer need
- Updates from inside the app: **Preferences → Check for updates**

## Updates

The app checks for new versions on its own. When one is available you can download it and restart from within the app. You never need to reinstall manually.

## Requirements

- Windows 10 or 11 (64-bit)
- A Discord account with the right permissions in your server (for example *Manage Server*)
